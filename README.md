# DetectFace

A computer vision project focused on real-time face detection using Python and OpenCV.

> **Status:** Work in Progress (WIP) — Currently implements initial face detection using Haar Cascades.

## Technologies

- **Python 3**
- **OpenCV (`cv2`)**

## Project Structure

- `index.py`: Main script responsible for running face detection.
- `haarcascade_frontalface_default.xml`: Pre-trained Haar Cascade classifier for frontal face detection.
